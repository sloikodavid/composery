---
name: grill
description: Use when the user wants to plan or talk about something complex.
---

Interview the user until you reach a shared understanding. Walk down each branch of the decision tree and resolve dependencies one by one.

Ask exactly one question at a time. Give your concise recommended answer and its reason with each question. Offer `y`/`n` to accept or reject the recommendation. Wait for the user's answer before you choose the next question; keep other branches internal.

Find facts yourself. Explore the codebase or authoritative sources instead of asking the user for information you can obtain. Ask the user only for judgments, preferences, and decisions.

Do not act on the result until the user confirms that you reached a shared understanding.

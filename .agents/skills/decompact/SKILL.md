Search the user directory to find and read your own *current* session with the user that usually looks like this `01a05bef-0bcf-7313-ac3b-9796a31a8870`. This may seem redundant but nets you crucial context that was already established in the conversation beforehand. The user most likely expects you to be on the same wavelength as them and remember it - don't betray that expectation.

# Store material

This directory tracks non-secret listing and review inputs. The store consoles
remain authoritative for submitted state; compare them with these files before
every release.

- `listing.md`: maintained public copy and URLs.
- `review-notes.md`: reviewer instructions with placeholders.
- `privacy.md`: evidence behind Apple App Privacy and Google Data Safety.

Never put reviewer passwords, API keys, private QR images, legal identity
documents, or console exports containing personal data here. Those belong in the
team password manager/private release record.

## Full description

Composery Mobile is the native companion for Composery instances.

Add an instance by URL or scan its QR code, keep multiple instances on your
device, and use the mobile-ready Composery IDE in a native shell. Composery can
connect to an instance you self-host or already have access to.

Native integration includes QR scanning, instance management, system theme and
safe-area handling, haptics, mobile back navigation, keyboard behavior, and
recovery when the embedded browser process or remote instance changes.

External pages open through your system rather than inside the instance view.
Camera access is optional and used only for QR scanning; a URL can always be
entered manually.

Composery Mobile is open source. It contains no advertising or cross-app
tracking.
